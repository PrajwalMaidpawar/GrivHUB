# GrievanceHUB System Limitations & Future Scope

## 1. Domain Disclaimer
GrievanceHUB is an academic research and software engineering project inspired by real-world electricity distribution workflows in Maharashtra (e.g. MSEDCL/Mahavitaran). It is not an officially affiliated product of any electricity distribution utility.

## 2. ML & Data Limitations
- Model trained on real public Indian civic electrical and utility complaint data.
- Categories with lower historical frequency in open public data rely on Laplace smoothing and rule-based fallback routing.
- Multilingual interface supports English, Hindi, and Marathi; text classifier is optimized for English and Hinglish text.

## 3. Future Scope
- Integration with smart IoT meters for automatic fault signaling.
- GIS map layers for field crew routing and asset GPS tracking.
